## 已知问题（不阻塞 M1，M2a 处理）

1. **引擎 size 参数为弱约束**（2026-07-19 实测）：方向大致生效、精确像素不生效。已在 Asset.meta 记录实际尺寸、比例文案不承诺精确像素；待与供应商确认口径。
2. **`VITE_API_TOKEN` 会被 `vite build` 打进前端产物**：dev 便利设计（值为本系统访问令牌，非引擎密钥）。生产构建须在无 `.env.local` 的环境执行，或改为运行时注入。
3. **失败 error 透传服务器本地路径**：如 `ENOENT …/storage/uploads/…`。M2a 应收敛为面向用户的错误码 + 服务端日志留详情。
4. NodeTemplate 维护走 `scripts/seed.mjs`（M3 前无管理界面），模板变更需重跑种子（版本号自动 +1）。
