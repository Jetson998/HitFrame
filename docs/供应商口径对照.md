## 待向管理员反馈（文档明示「联系管理员」渠道）

**size 实测不符**：请求值均在文档三档内，但返回尺寸多次不一致——

- 请求 `1024x1024` → 返回 1086×1448（3:4）
- 请求 `1536x1024` → 返回 1402×1122（≈5:4）
- 2026-07-20 商品图案例：请求 `1024x1024` → 返回横幅（≈3:2）

需确认：是否 size 仅作方向性提示？是否有严格模式？在答复前，产品侧维持「比例按方向生效、不承诺精确像素」的文案口径，`Asset.meta` 记录实际尺寸。
