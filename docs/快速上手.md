# HitFrame 快速上手：三条典型流程

面向客户运营/内容团队的实际操作手册。以下三条流程对应首页「快速开始」的三张模板卡片，也可以从「AI 图片 → 场景模板」进入。

三条流程操作路径完全一致，只是每步的选项不同：**上传/选择图片 → 填写场景选项 → 设置输出（比例/清晰度/数量）→ 生成 → 等待结果 → 存入资产库**。

## 流程一：商品换背景

**适合场景**：电商主图批量出不同背景版本，替代外包摄影精修。

1. 首页点「商品换背景」卡片，或 AI 图片页选「场景模板」Tab → 商品换背景
2. **上传商品图**（必填，1 张）——建议主体清晰、背景干净的商品图，效果更好
3. 选**背景风格**：木质桌面 / 大���石台面 / ins 柔光 / 纯色背景 / 节日氛围（默认木质桌面）
4. 选**光影氛围**：自然光 / 柔光 / 暖光 / 冷光（默认柔光）
5. 设置输出：比例（1:1 电商主图常用）、清晰度（标准 2 点/张，高清 4 点/张）、数量（1–4 张候选，一次多张方便挑选）
6. 点「生成」，等待结果（页面自动轮询，无需手动刷新）
7. 生成完成后自动进入资产库，可点开选最满意的一张下载/复用

## 流程二：模特上身 / 真人试穿

**适合场景**：服装/配饰类目，把平铺图变成真人上身效果，用于详情页/营销素材。

1. 首页点「模特上身」卡片，或场景模板 → 模特上身
2. **上传服装/商品图**（必填）——平铺图或产品图均可
3. **模特参考图**（可选）——如果有具体想要的模特风格/姿态参考可以上传，不上传则用下方选项描述生成
4. 选**人物风格**：时尚模特 / 日常穿搭 / 运动健身 / 商务正装 / 街头潮流（默认时尚模特）
5. 选**姿态**：自然站姿 / 侧身展示 / 动态pose / 半身特写
6. 选**场景**：纯色背景 / 室内场景 / 户外街景 / 工作室
7. 设置输出、生成、等待结果——同流程一

## 流程三：电商海报 / 小红书封面

**适合场景**：商品图 + 文案快速出营销海报/种草封面，直接可用于投放或发布。

1. 首页点「电商海报」卡片，或场景模板 → 电商海报
2. **上传商品图**（必填）
3. 填**标题文案**（必填）——例如"夏日新品"、"限时特惠"
4. 填**核心卖点**（可选）——例如"买二送一"、"全场包邮"
5. 选**设计风格**：简约现代 / 国潮风 / 小清新 / 高端奢华 / 活力撞色
6. 建议比例选 **3:4** 或 **9:16**（竖版更适合小红书/朋友圈封面）
7. 生成、等待结果——同流程一

## 也可以用 Agent（自然语言描述需求）

不想逐项选选项，也可以在 Agent 页直接用一句话描述需求，例如：

> 商品换大理石背景，1张，1:1

Agent 会自动解析出对应模板、比例、数量、清晰度，展示解析结果和预计点数，**你确认后才会真正生成**（不会因为描述而自动扣点）。

## 通用提示

- **点数消耗** = 数量 × 单张点数（标准 2 点/张，高清 4 点/张），生成前会显示预计消耗，生成失败会自动退还，不用担心失败白扣点
- **实际输出尺寸**跟请求比例可能有细微差异（引擎特性），系统按实际尺寸展示，不影响使用
- 所有生成结果和上传素材统一在「资产库」管理，可按项目归类、按类型筛选、删除、再次引用
- 生成结果可以点开详情，点「引用为参考图」直接拿去做下一轮图生图
